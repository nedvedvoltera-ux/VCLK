# VCLK для iOS

Нативный клиент (SwiftUI + LiveKit Swift SDK 2.12.1), iOS 16+. Проект описан в `project.yml`, Xcode-проект генерируется [XcodeGen](https://github.com/yonaskolb/XcodeGen).

## Сборка на Mac

1. Нужны Xcode 15 или новее и XcodeGen: `brew install xcodegen`.
2. В папке `ios/` выполните `xcodegen generate` — появится `Vclk.xcodeproj`.
3. Откройте проект, выберите цель **Vclk** → *Signing & Capabilities*:
   - Team — ваш Apple ID (Xcode → Settings → Accounts → Add Account);
   - если идентификатор `ru.asntl.vclk` занят, поменяйте Bundle Identifier на свой.
4. Подключите iPhone (включите *Настройки → Конфиденциальность и безопасность → Режим разработчика*), выберите его как устройство и нажмите Run.
5. При первом запуске на устройстве: *Настройки → Основные → VPN и управление устройством* → доверять своему профилю.

Тесты: `Cmd+U` (цель `VclkTests`).

## Ограничения

- Бесплатный Apple ID: приложение работает 7 дней, потом нужно переустановить из Xcode. Платный аккаунт снимает ограничение и даёт TestFlight.
- Ссылки `https://host/room…` и `/invite/…` не открываются в приложении сами (для этого нужны Associated Domains платного аккаунта). Вставьте ссылку: меню профиля → «Открыть по ссылке…».
- Нет: демонстрации своего экрана (чужую показ видно), разделов настроек, архива записей, перетаскивания встреч в календаре; недели и дни в календаре показаны списком.
- Для работы по `http://` в локальной сети включён ATS-исключение; при первом обращении iOS спросит доступ к локальной сети.
